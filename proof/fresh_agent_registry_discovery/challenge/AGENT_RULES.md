# Agent Rules

- Search the portable capability registry before coding.
- Treat the portable registry and exported metadata/packages as the only capability authority.
- Create `CAPABILITY_PLAN.yml` before implementation files.
- Prefer reuse -> configure -> compose -> local gap.
- Keep domain vocabulary in the project; do not push Shipment Exception semantics into shared packages.
- Use public interfaces rather than copying shared implementations.
- Do not access the source monorepo, other repositories, web search, or hidden evaluator files.
